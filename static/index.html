    🧠 使用帮助

    三种输入方式

    • 粘贴（推荐）：在下方对话框按 Ctrl+V / Cmd+V，截图自动 OCR 识别，文本棋盘自动解析
    • 手动编辑：点击棋盘格修改状态；上传截图按钮选择图片文件识别
    • 加载示例：下拉菜单快速载入经典残局

    棋盘编辑

    • 左键：未知 → 数字 1→2→…→8 → 回到未知
    • 右键：插旗 🚩 / 取消旗帜
    • Shift + 左键：清除为已翻开的 0

    文本棋盘格式

    ? / -1 = 未知，F / 🚩 / -2 = 旗帜，0-8 = 已翻开数字，支持空格或逗号分隔，每行一排。

    结果解读

    • 🟢 绿色覆盖 = 必安全 · 🔴 红色覆盖 = 必雷 · 蓝色百分比 = 蒙特卡洛雷概率
    • 点击右侧推理链步骤，棋盘将高亮该步涉及的格子（橙框）
    • 悬停已高亮格子可查看概率与依赖信息

    模式说明

    • 答案模式：给出完整“因为…所以…”推理链
    • 策略模式：基于概率与收益，比较各区域利弊
    • 教学模式：不给答案，逐步引导提问，帮你顿悟
